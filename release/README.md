# Windows 下载包

Windows 发行包通过 GitHub Releases 分发，文件名 `MarkdownToWord-Windows.zip`，包含：

- `MarkdownToWord.exe`
- `_internal` 运行库和 Pandoc
- 启动脚本、使用说明和第三方组件说明

从 [Releases](https://github.com/lzgqaq/MarkdownToWord/releases/latest) 下载后完整解压，再运行 `启动程序.cmd` 或 `MarkdownToWord.exe`。

发行包中的 `pandoc.exe` 体积较大，因此不再提交到 Git 仓库；仓库只保留源码、构建脚本和发行说明。
