# 第三方组件

本工具通过独立子进程调用 Pandoc。各组件保留自己的许可。

| 组件 | 构建版本 | 项目与源码 |
| --- | --- | --- |
| Python | 3.12.10 | https://www.python.org/downloads/release/python-31210/ |
| Tcl/Tk | 8.6 | https://www.tcl.tk/software/tcltk/ |
| Pandoc | 3.9 | https://github.com/jgm/pandoc/tree/3.9 |
| pypandoc_binary | 1.17 | https://github.com/JessicaTegner/pypandoc |
| PyInstaller | 6.22.3 | https://github.com/pyinstaller/pyinstaller |

Python 许可、Pandoc 及其组件版权清单、Tk 许可和 PyInstaller 许可副本放在 `licenses` 文件夹。PyInstaller 的引导程序适用其随附许可中的特别例外。Pandoc 对应源码发布地址：https://github.com/jgm/pandoc/releases/tag/3.9 。

本程序源码位于 `source`，可供个人使用和修改。第三方组件的许可不因本工具的分发而改变。
